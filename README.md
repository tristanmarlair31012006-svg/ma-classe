# Ma classe – DASPA

App web pour iPad, faite pour la classe DASPA de l'Athénée Royal de Huy : leçons multilingues, Atelier (carte, frise, dessin, trace, BD), Mes mots et discussion traduite.

- Les données des élèves restent sur chaque iPad. Ce dépôt ne contient aucune donnée d'élève.
- Mise à jour : remplacer les fichiers, puis augmenter `VERSION` dans `sw.js`.
